# Oxbow

**Your database client. Your agent's, too.**

A modern desktop database client for macOS. Explore schemas, write SQL, manage data, and work with AI agents through a built-in MCP server.

**PostgreSQL · MySQL · macOS**

## Features

- **Built-in MCP server** — Connect Claude Code, Codex, Gemini CLI, or any MCP-compatible AI agent. Control which databases and tables agents can access, with read-only access by default and human-reviewed writes.
- **SQL editor** — Write and execute queries with intelligent autocompletion, SQL formatting, saved queries, and multi-statement execution.
- **Visual schema explorer** — Explore tables, relationships, primary keys, and foreign keys through interactive database diagrams.
- **Data editing** — Insert, update, and delete rows with pending changes and SQL previews before committing.
- **Database structure** — Inspect columns, indexes, constraints, triggers, and DDL.
- **Query history** — Revisit previously executed statements and their results.
- **Data export** — Export query results to CSV, Excel, JSON, SQL, Markdown, and more.
- **Secure connections** — Connect to local or remote databases with TLS and SSH tunnel support. Credentials are stored in the system keychain.

## Download

Oxbow is currently available as a public beta for macOS.

Download the latest version from [GitHub Releases](https://github.com/oxbow-app/releases/releases/latest).

**Requirements:** macOS with Apple Silicon (M1 or later).

## Installation

1. Download `Oxbow-macOS-arm64.dmg` from the latest release.
2. Open the disk image and drag Oxbow into Applications.
3. Launch Oxbow.
